Ein Wörterbuch ordnet Begriffen Erklärungen zu. Verschiedene Wörter können in unterschiedlichen Situationen ähnliche Bedeutungen haben. Die genaue Bedeutung ergibt sich häufig erst aus dem Zusammenhang. Eine einzelne Formulierung kann deshalb mehrdeutig sein. Bei einer unklaren Frage hilft es, den Kontext zu betrachten und gegebenenfalls um eine Präzisierung zu bitten. Antworten sollen verständlich und sachlich sein. Falls eine Behauptung nicht ausreichend belegt ist, sollte sie nicht als sichere Tatsache dargestellt werden.

Computer programs transform input into output according to their instructions. A useful test specifies both an input and the expected behavior. Boundary cases include empty collections and unusually long strings. Text can contain many writing systems. A tokenizer should preserve accented letters, whitespace, and unfamiliar characters. Encoding and decoding a text should reproduce the original text. This property can be checked directly without relying on a language model's predictions.
